# Sporium

<img src="public/branding/mark-256.png" width="128" alt="Sporium" />

Лаунчер Minecraft для Windows x64: единая библиотека сборок, локальные профили и каталог Modrinth.

## Установка

Скачайте **SporiumLauncher.exe** в [разделе Releases](https://github.com/opensxul/sporium-launcher-v-1.0.0/releases) и запустите установщик. Программа устанавливается для текущего пользователя. Если WebView2 отсутствует, установщик загрузит его с сервера Microsoft.

Сборки и настройки хранятся отдельно, в `%LOCALAPPDATA%\app.sporium.launcher`. Повторная установка сохраняет эти данные. При удалении программы не включайте пункт удаления данных приложения, если хотите сохранить библиотеку.

Новые версии предлагаются внутри лаунчера после запуска. Установка начинается по подтверждению пользователя, после загрузки и проверки подписи пакета. На время обновления завершите игру и загрузки контента.

## Возможности

- Vanilla, Fabric, Forge и NeoForge; автоматическая загрузка совместимой Java.
- Общие для всех локальных профилей сборки, избранное, папки и пользовательские иконки.
- Моды, ресурспаки и шейдеры из Modrinth; добавление контента прямо из открытой сборки.
- Создание совместимой сборки при установке мода, проверка зависимостей и управление обновлениями контента.
- Импорт `.mrpack` и `.sporium`, экспорт, перенос поддерживаемых сборок из других лаунчеров.
- Локальные JAR, карты и датапаки, точки восстановления и журнал изменений.
- Русский и английский интерфейс, предпросмотр скина по нику.

**Доступны одиночная игра и LAN. Realms и серверы с обязательной проверкой Microsoft-аккаунта требуют авторизации.** В этой версии вход через Microsoft не реализован; локальный профиль не создаёт авторизованную Microsoft-сессию.

Поддержка исторических версий имеет ограничения: [матрица запуска](docs/VANILLA_LAUNCH.md). Sporium не связан с Mojang, Microsoft или Modrinth.

## Разработка

Нужны Windows x64, Node.js 24.19+, Rust 1.98+ MSVC, Visual Studio C++ Build Tools / Windows SDK и WebView2. Версии зависимостей закреплены в lock-файлах.

```powershell
npm.cmd ci
npm.cmd run desktop
```

`npm.cmd run desktop:build` собирает автономный отладочный EXE в `src-tauri/target/debug/Sporium.exe`. `npm.cmd run installer:build` собирает установщик и файлы обновления в `releases/`; нужен ключ подписи. [Сборка и выпуск обновлений](docs/RELEASING.md).

Проверки: `npm.cmd test`, `npm.cmd run lint`, `npm.cmd run test:ui`, `cargo test --manifest-path src-tauri/Cargo.toml`. Нативные проверки используют изолированные данные внутри `.local`; перед ними выполните `npm.cmd run desktop:build`. Проверка установщика: `powershell -ExecutionPolicy Bypass -File scripts/installer-smoke.ps1` (отказывается работать поверх существующей установленной копии).

Основной код: React/TypeScript в `src`, Rust/Tauri в `src-tauri/src`. `src-tauri` — исходники, удалять эту папку нельзя. `src-tauri/target` — восстанавливаемые результаты компиляции. `scripts/backup-source.ps1` сохраняет локальную резервную копию исходников.
