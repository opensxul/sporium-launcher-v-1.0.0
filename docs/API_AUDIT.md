# Initial API audit — 2026-09-26

This is a discovery record, not a claim of tested game support. Recheck exact version metadata when implementing each resolver.

| Area         | Primary evidence                                                                                                           | Decision / verification                                                                                                                                                                                                                                                                   |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tauri        | https://v2.tauri.app/start/prerequisites/ and https://v2.tauri.app/develop/calling-rust/                                   | Windows MSVC + WebView2. Async commands offload blocking filesystem/SQLite work. Expose only named operations.                                                                                                                                                                            |
| IPC security | https://v2.tauri.app/security/capabilities/                                                                                | Local main window only, restrictive CSP, no general filesystem/shell/network access from the renderer.                                                                                                                                                                                    |

Never derive runtime requirements from a version-name heuristic.                                                             |
| Fabric       | https://github.com/FabricMC/fabric-meta/blob/master/README.md                                                              | Live `/v2/versions/loader/26.3` response includes loader 0.19.5, libraries, main class and minimum Java metadata. Merge official profile metadata through a dedicated resolver. Fabric API is separate content.                                                                           |
| Forge        | https://github.com/MinecraftForge/Installer/blob/2.0/src/main/java/net/minecraftforge/installer/actions/ClientInstall.java | Official installer source distinguishes InstallV1 and newer install profiles/processors. | Microsoft    | https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow                                         | Public native application, authorization code + PKCE, system browser, state validation. | Modrinth     | https://docs.modrinth.com/api/                                                                                             | Live `/v2/search?query=sodium&limit=1` succeeds. File-level loader/game compatibility and dependencies are authoritative.                                                           |
| CurseForge   | https://docs.curseforge.com/rest-api/                                                                                      | API uses `x-api-key`; distribution metadata includes `allowModDistribution`. Proposed architecture: approved service-side proxy retaining private credentials, with provider links/manual fallback for restricted downloads. Not yet approved or deployed; integration gated at phase 10. |

## Scope and constraints

- No API secrets, accounts or tokens were read from the machine.
- Official auth is not verified until a registered Sporium application completes the service flow with a test account. OAuth documentation alone does not establish Minecraft API access.
- No Microsoft/CurseForge backend is provisioned by foundation work.
- Home uses provisional code-native shapes and typography. Final artwork belongs to the phase 14 asset gate.
- Launcher features progress in the order defined by the supplied master specification. No game launch, installer or signed update is part of phase 1.
