# Sporium Launcher 2.0.0 · Mushroom Forest

Домашний экран объединяет запуск Vanilla, профиль игрока, статус сервера, новости и галерею. Библиотека сборок, Modrinth, папки, загрузчики, импорт и восстановление доступны через боковое меню. Оригинальная иконка Sporium используется в приложении и установщике.

В комплекте указан сервер `ru1.anonix.cloud:25672`. При проверке 17 ноября 2026 года он сообщил Paper 26.3. Адрес и резервная версия хранятся в `config/sporium.json`.

В **Настройки → Minecraft** можно указать адрес сервера и версию игры. Версия из настроек имеет приоритет над ответом сервера. Для штатного адреса при отсутствии ответа используется последняя подтверждённая версия. Для другого адреса при отсутствии обеих версий главная предлагает имеющуюся Vanilla-сборку или открывает настройки. При первом запуске выбранной версии лаунчер создаёт сборку и проверяет файлы. Автоподключение включено для кнопки на главной. Его можно отключить в настройках Minecraft. Ручной запуск сборки из библиотеки сохраняет прежнее поведение.

Статус использует TCP-запрос Minecraft Java. Лаунчер показывает число игроков, версию и время ответа на Ping. Отказ в подключении, ошибка сети и отсутствующий адрес отображаются раздельно. Для сервера с отдельной SRV-записью укажите фактический хост и порт.

В **Настройки → Дополнительно** можно подключить HTTPS-источник новостей и фотографий, проверить обновления и выбрать параметры Windows. Источник возвращает JSON следующей структуры. Массивы можно оставлять пустыми.

```json
{
  "news": [],
  "gallery": []
}
```

Элемент `news` содержит строки `title`, `date` (ISO 8601), `summary`, `body` и необязательный `image`. Элемент `gallery` содержит `title`, `image` и необязательный `thumbnail`. Изображения должны быть на том же HTTPS-источнике. Поддерживаются JPEG, PNG и WebP. Текст публикаций выводится как обычный текст. При отсутствии материалов доступны пустые состояния.

Локальные профили из 1.0.1 доступны после обновления. Для Microsoft-входа оператору нужен собственный одобренный идентификатор публичного клиента с разрешённым потоком device code. Задайте `SPORIUM_MICROSOFT_CLIENT_ID` при сборке или при запуске. В разделе «Профиль» выберите вход у профиля с соответствующим игровым ником. После подтверждения в браузере Sporium проверяет права на Java Edition и игровой UUID. Привязанный профиль использует UUID Microsoft, который может отличаться от прежнего UUID локального игрока. Refresh-токен хранится в SQLite под защитой Windows DPAPI. Удаление профиля удаляет его привязку.

Путь библиотеки можно переключить в настройках хранилища. Открывается самостоятельная библиотека со своими профилями после перезапуска. Вернуть прежнюю можно выбором её каталога. Для одного запуска доступен `Sporium.exe --library "D:\Games\Sporium"` с существующей пустой папкой или библиотекой Sporium. Закрытие приложения во время игры блокируется менеджером процессов. Доступны сворачивание окна и работа из системного трея.

Тема учитывает системное уменьшение движения. Споры, параллакс и интенсивность настраиваются отдельно. Фоновая иллюстрация создана для лаунчера и размещена в `public/branding/mushroom-forest.webp`. В галерею попадают только фотографии из настроенного источника.

Minecraft 26.3 использует SDL и LWJGL. Если штатный путь к их библиотекам приближается к пределу Windows, Sporium распаковывает проверенные нативные файлы в короткий временный каталог. Каталог принадлежит игровой сессии и очищается после её завершения.

При первом запуске новой сборки Minecraft может показать свой экран специальных возможностей. Автоподключение продолжится после завершения начальной настройки в игре.
