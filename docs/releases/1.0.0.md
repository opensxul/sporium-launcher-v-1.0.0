# Sporium 1.0.0

Первый установочный выпуск Sporium для Windows x64.

- Общая библиотека сборок и свободный выбор локального ника.
- Minecraft Vanilla, Fabric, Forge и NeoForge; загрузка совместимой Java.
- Каталог Modrinth и добавление совместимых модов, ресурспаков и шейдеров прямо из сборки.
- Импорт и экспорт сборок, управление контентом и точками восстановления.
- Русский и английский интерфейс, фирменный логотип Sporium.
- Проверка обновлений лаунчера через GitHub с проверкой цифровой подписи пакета.

Доступны одиночная игра и LAN. Realms и серверы с обязательной проверкой Microsoft-аккаунта требуют авторизации.

Управление серверами, дальнейшее оформление и стандартные логотипы сборок запланированы в следующих обновлениях.
